# REST API для работы с пользователями
## Методы API:
### 1. Создание пользователя**POST** /user/create
#### Параметры:
- email (string) - Email пользователя
- password_hash (string) - Пароль
### 2. Обновление информации пользователя
PUT /user/update/{id}
#### Параметры:
- id (int) - ID пользователя
- email (string) - Новый email
- password_hash (string) - Новый пароль
### 3. Удаление пользователя
DELETE /user/delete/{id}
#### Параметры:
- id (int) - ID пользователя
### 4. Авторизация пользователя
POST /user/login
#### Параметры:
- email (string) - Email пользователя- password (string) - Пароль
### 5. Получение информации о пользователе**GET** /user/view/{id}
#### Параметры:
- id (int) - ID пользователя
### Дополнительно:
#### Для следующих методов API требуется аутентификация: Создание пользователя, Обновление информации пользователя, Удаление пользователя, Получение информации о пользователе. 
#### К данным методам в запросе необходимо дополнительно передавать параметр key в заголовке запроса. Его значение можно узнать из поля auth_key базы данных для созданных юзеров.
